---
type: "practice"
title: "Mover código reutilizable de notebooks a módulos"
applies_to: ["python"]
---

Usa notebooks para explorar y explicar. Mueve transformaciones y entrenamiento reutilizables a módulos probados con entradas explícitas. Reinicia y ejecuta todas las celdas en kernel limpio; ofrece script o módulo para ejecución desatendida. Conserva salidas pequeñas y sin datos sensibles.
