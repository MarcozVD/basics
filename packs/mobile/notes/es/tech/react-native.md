# React Native

React Native construye interfaces móviles con React y componentes nativos. Elige módulos compatibles, prueba en dispositivos y explicita código por plataforma. TypeScript no valida payloads de red ni permisos nativos.

Notas relacionadas: [[expo]], [[typescript]], [[react-native-mmkv]], [[react-native-testing-library]].

[Referencia oficial](https://reactnative.dev/docs/getting-started).
