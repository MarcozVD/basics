# Jetpack Compose

Jetpack Compose es un toolkit UI Android con composables Kotlin. Define quién posee el estado, maneja ciclo de vida y prueba semántica accesible. Esta nota trata Compose Android, no promete UI iOS compartida; verifica otras herramientas multiplataforma aparte.

Notas relacionadas: [[kotlin]], [[flutter]], [[swiftui]].
