Make the review diff and Inbox easier to scan. New notes show a single unified diff, updates keep three lines of context around each change, and every proposal opens with a one-line summary. The summary names the layer note, so a Spanish vault reads the layer's own title. The Inbox can filter pending proposals by the agent that wrote them, Approve all follows the active filters and says what it will approve, and the bulk buttons stay in place when only one proposal is pending. Opening the Inbox focuses the selected row, arrows move through the list, and the command palette leads with Review next proposal when something is waiting.
