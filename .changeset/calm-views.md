Simplify Home, Projects, Recommend, Inbox, Explore, Skills and Settings to one main task per screen. Home opens with one line of vault health, then waiting proposals, Continue where you left off (your recent notes and projects), three activity rows with Show all, and a single Get set up line while steps are open. Projects rows show the name, status and update time, and add a line only when checks fail or technologies are missing. Recommend puts the prompt first and folds the layer options into one line. Inbox rows show the type, title, action, author and age; the reason and the Approve, Edit and approve, and Reject actions open in the detail panel, or on the proposal page below 1280px. Explore keeps its search, type, layer, sort, view and New note in one toolbar row; its default columns are title, layers, tags and updated, the note ID appears on hover or focus, and Source appears only when the vault mixes agent, pack and hand-written notes. Skills has one filter row with an agent select, and each skill's area control sits in its Details. A page's intro sits under its title until the page has content, then moves behind a ? in the header; each intro can be dismissed. The note title wraps on narrow windows instead of being clipped.
