Simplify Home, Projects and Recommend to one main task per screen. Home opens with one line of vault health, then waiting proposals, Continue where you left off (your recent notes and projects), three activity rows with Show all, and a single Get set up line while steps are open. Projects rows show the name, status and update time, and add a line only when checks fail or technologies are missing. Recommend puts the prompt first and folds the layer options into one line. A page's intro sits under its title until the page has content, then moves behind a ? in the header; each intro can be dismissed. The note title wraps on narrow windows instead of being clipped.
