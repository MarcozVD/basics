Replace the floating Dock with a navigation sidebar and a single content panel. The sidebar holds the same screens, with an expanded width, an icon rail and a drawer on narrow windows, and Ctrl/Cmd+B toggles it. Settings > General > Navigation can switch to a floating bar that you drag to any edge, with arrow keys for keyboard users. The desktop app shows a thin title strip with the window controls. Language and theme move into Settings only.
